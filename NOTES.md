# DG Chocolatier — One-Pager (chocobonbon.mk)

Premium Belgian chocolate brand one-pager. Three visual directions delivered for client review.

## Files

| File | Purpose |
|---|---|
| `index.html` | **✓ FINAL — production version.** The light/warm/artisanal direction (v1) the client chose. Deploy this to chocobonbon.mk. |
| `preview.html` | Comparison page showing all 3 originally proposed directions (kept for reference; not for production). |
| `v2-dark.html` | Alternate — dark cocoa + gold. Boutique luxury feel. |
| `v3-editorial.html` | Alternate — magazine layout, Bodoni Moda. |
| `logo.png` | DG Chocolatier logo, transparent PNG (`Logo/Final .png`). |
| `Logo/` | All logo variants supplied by client. Production uses `Final .png`. |

`index.html` is a full one-pager: Hero → About → Belgian story → Products → Custom orders → Contact, in Macedonian, using the transparent `logo.png` directly.

## Placeholders to replace before launch

Search-and-replace across all three HTML files:

| Placeholder | Replace with |
|---|---|
| `{{PHONE}}` | The owner's phone number (e.g. `+389 70 123 456`) |
| `{{INSTAGRAM}}` | The Instagram handle without `@` (e.g. `dgchocolatier`) |
| `{{LOCATION}}` | Street address / city (e.g. `Прилеп, Македонија`) |

## Photography

Product photos throughout are **Unsplash placeholders** — use them for client review only. Before launch, replace with real photos of:
- Her actual bonbons / pralines / truffles (4 hero shots)
- The chocolatier at work (1 portrait / studio shot)

Search for `images.unsplash.com` in the HTML to find every image URL to swap.

## Domain

Domain `chocobonbon.mk` is owned and ready to redirect / point to whichever version is chosen. Hosting deployment can follow once a version is selected.

## Picking a direction

The light version (v1) was built as the primary because the client requested a light aesthetic. The other two exist so the client can compare and confirm the choice — or pick visual elements from each to remix into a final.
